# 🚀 CryptoPulse

CryptoPulse is a responsive cryptocurrency tracking web application built with React and Vite. It uses the CoinGecko API to display cryptocurrency market data, price charts, watchlists, and coin comparison features.

## ✨ Features

- 📊 Top 20 cryptocurrencies by market capitalization
- 🔍 Search cryptocurrencies
- ↕️ Sort cryptocurrency data
- 📈 View 7-day price charts
- ⭐ Add and remove coins from Watchlist
- 💾 Watchlist saved using Local Storage
- ⚖️ Compare two cryptocurrencies with price charts
- 🌙 Dark and Light mode
- 💾 Theme preference saved using Local Storage
- 📱 Fully responsive design
- ⏳ Loading states
- ⚠️ Error handling

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- CSS
- React Router
- Recharts
- Axios
- CoinGecko API
- Local Storage

## 🌐 API

CryptoPulse uses the CoinGecko API to retrieve cryptocurrency market data and historical price information.

API: https://api.coingecko.com/api/v3

## 📊 Main Sections

### Market

Displays the top 20 cryptocurrencies with information such as:

- Cryptocurrency name
- Symbol
- Current price
- Market capitalization
- Market rank
- 24-hour price change

### Coin Details

Users can click on a cryptocurrency to view its detailed information and 7-day price chart.

### Watchlist

Users can add their favorite cryptocurrencies to a personal watchlist. The watchlist is saved in Local Storage and remains available after refreshing the page.

### Compare

Users can select two cryptocurrencies and compare their 7-day price movements on the same chart.

### Theme

CryptoPulse supports Dark Mode and Light Mode. The selected theme is saved in Local Storage.

## ⚙️ Installation

Clone the repository:

git clone https://github.com/eimanshakoor502-os/CrytoPulse.git

Go to the project folder:

cd CrytoPulse

Install dependencies:

npm install

Start the development server:

npm run dev
